# Lumina Bible

Read, listen to, and study the Holy Bible — **offline-first**, in English, French, Swahili,
Lingala (with Tshiluba UI). Installable as a real app on **Android, iPhone/iPad, Windows,
macOS and Linux** from a single web address.

## Features

- 📖 66-book Bible reader with bookmarks, highlights, notes and reading plans
- 🎧 Audio Bible (text-to-speech per translation)
- 🔍 Verse search
- 🙏 Prayer list & journal (stored on-device)
- 📴 **True offline mode** — every chapter you open is cached, and full translations can be
  downloaded to the device (Settings → Offline Bibles) so the whole Bible works with zero signal
- 📲 Installable PWA: Android "Add to Home screen", iOS "Add to Home Screen",
  Chrome/Edge "Install app" on PC — no app store needed

## Architecture

| Layer | What it does |
| --- | --- |
| Next.js 16 (App Router) | UI + API routes |
| `public/bible/*.json` | **Bundled offline packs** — full WEB (English), Louis Segond (French), ULB Swahili and Lingala Bibles, generated by `npm run data:offline`. These make the app run with **no database and no upstream network** |
| PostgreSQL + Drizzle *(optional)* | Caches chapters opened through the app, powers fast DB search. Not required |
| IndexedDB (`idb-keyval`) | Client-side full-translation packs + chapter cache |
| Service worker | App-shell + API caching so the installed app opens offline |

### Content sources & licences

| Slot in app | Source text | Licence |
| --- | --- | --- |
| `ESV` | World English Bible (`eng-engwebp`) | Public domain |
| `LSG` | Louis Segond 1910 | Public domain |
| `SW` | Biblia Takatifu — Unlocked Literal Bible (`swh-swhulb`) | CC BY-SA 4.0 (Door43) |
| `LIN` | Salela na bonsomi / Mokanda na Bomoi (`lin-lin`) | Biblica® — verify redistribution terms before wide release |
| `LUA` (Tshiluba) | No open-licensed corpus exists — falls back to English | UI names are translated |

> The data generator (`scripts/fetch-offline-bible.mjs`) pulls from
> [BibleNLP/ebible](https://github.com/BibleNLP/ebible). Note: the ESV is a copyrighted
> Crossway translation; the "ESV" slot therefore serves the public-domain World English Bible
> so the app can legally ship full English text. Relabel the slot or add a licensed ESV feed
> if you obtain permission.

## Quick start

```bash
npm install

# optional: point at PostgreSQL and seed it
cp .env.example .env          # edit DATABASE_URL
npx drizzle-kit push          # create tables
npm run seed                  # seed plans + sample verses

npm run dev                   # http://localhost:3000
```

**No database? No problem.** Every route falls back to the bundled packs in `public/bible`,
so `npm run dev` / `npm run build && npm start` work out of the box.

### Useful scripts

| Script | Purpose |
| --- | --- |
| `npm run data:offline` | Re-generate `public/bible` packs from the eBible corpus (cached in `.cache/`) |
| `npm run seed` | Seed PostgreSQL with plans + sample verses |
| `npm run typecheck` / `npm run lint` | Checks |

## Deploying (Vercel)

1. Push this repo to GitHub and import it in [vercel.com](https://vercel.com) — Next.js is
   auto-detected, no config needed.
2. **(Optional)** Add a Postgres database (Vercel Marketplace → Neon/Supabase) and set the
   `DATABASE_URL` env var. Skip this step and the app still runs entirely on bundled packs.
3. Deploy. Your site gets HTTPS automatically — required for PWA installs.

## Installing the app

After deployment, open the URL and install like any native app:

| Platform | How |
| --- | --- |
| **Android (Chrome)** | Browser menu → *Install app* / *Add to Home screen* (or the install icon in the address bar) |
| **iPhone / iPad (Safari)** | Share button → *Add to Home Screen* |
| **Windows / Linux (Chrome or Edge)** | Address-bar install icon → *Install*, or Menu → *Cast, save and share* → *Install page as app* |
| **macOS (Chrome/Edge/Safari)** | Chrome/Edge: same as Windows · Safari: Share → *Add to Dock* |

Once installed, Lumina Bible opens full-screen in its own window with its own icon.
Download a translation in **Settings → Offline Bibles** first if you need guaranteed
zero-signal reading (flights, remote areas, data-saving).

## Project layout

```
public/bible/<CODE>/<book>.json   bundled offline packs (generated, committed)
public/sw.js                      service worker (offline shell + API cache)
public/manifest.webmanifest       PWA manifest
scripts/fetch-offline-bible.mjs   pack generator (GitHub eBible corpus)
src/app/api/*                     chapter / search / plans / available routes
src/lib/offline.ts                IndexedDB pack store + downloader (client)
src/lib/bible/packs.server.ts     server-side pack reader (DB-less fallback)
src/lib/store.tsx                 app state (offline-first chapter reads)
```
